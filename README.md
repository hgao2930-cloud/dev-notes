## 1. Express 路由参数：res 被当成了 req

**问题**

点「退出登录」没反应，页面上也没有任何报错提示；只有打开 Network 才看到接口返回了 500。去后端看日志，真正的报错是 `res.clearCookie is not a function`。

**原因**
Express 路由参数需要的是req,res,next，不是一定要有三个，但是顺序不能错，这三个分别对应请求数据，返回数据，以及给到下一个中间件处理，不需要用到的参数可以用_在前面来避免检查，
**解决办法**
加上参数
**深入思考**
Express 对参数的识别和js里的函数是一样的，不是一个实例上的三个属性，是三个参数
